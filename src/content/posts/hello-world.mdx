Markdown in, static HTML out — with interactivity where it earns its place.

This blog is built on a simple principle: ship **zero JavaScript by default**, then
hydrate small, isolated islands only where a page genuinely needs to be interactive.
A diagram costs nothing at runtime. A chart loads its code only when you scroll to it.
A Python sandbox waits until the browser is idle before it wakes up.

Head to the [interactive demo](/posts/interactive-demo) to see all four tiers at once.
